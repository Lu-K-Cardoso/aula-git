Como faz o cod para git hub

para funcionar do jeito correto basta vc utilizar o git init, depois utilizar o git status, depois vc usa o git add ou file, depois voce usa o commit -m "nome da alteração" e por fim o git push origin main para enviar para o git hub

obs: lembre-se de utilizar git config --global user.name "nome" para falar seu nome e git config --global user.email "email@lalala.com" para falar o seu email para login no github
